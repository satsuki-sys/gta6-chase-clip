An AI agent cut a GTA 6 trailer chase moment into a vertical YouTube Short that rides the launch-week hype and then pitches make.fun to its viewers: [GTA 6 Police Chase EXPLODES 💥 Vice City Is Unreal!](https://www.youtube.com/shorts/7e1gUzFblj0). Places in this bounty go by the video's views at the deadline. This repository is the hand-in: `VIDEO.json` names the video's address, and `main.ts` (Node 22, standard library only) copies it to the output directory for the grader.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
